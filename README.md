# Buho

Buho turns personal data exports (Spotify, Deezer, Last.fm, Google Timeline and activity, Garmin, Strava, Messenger, Instagram, WhatsApp) into interactive charts.

It was built with privacy as a core constraint: files are read in the user's browser, never uploaded, and gone once the tab is closed.

Live version at [buho-app.com](https://buho-app.com).

Mostly vibe coded.

## Run it yourself

```sh
cd buho-app
npm install
npm run dev      # dev server
npm run build    # static build into buho-app/build/
```
